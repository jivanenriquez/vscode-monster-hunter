# vscode-mh

A Monster Hunter pet that walks, runs and idles in the Explorer sidebar. Built on the ideas of
[vscode-pets](https://github.com/tonybaloney/vscode-pets).

## Install from a clone

```
npm install
npm run package
code --install-extension vscode-mh-0.0.1.vsix
```

Reload VS Code. The pet shows in the Explorer as "Monster Hunter". Pick a pet from the status bar
item or the "Start Monster Hunter pets" command.

## Dev

`npm run dev` opens an Extension Development Host.
